# Paper-output coverage and execution order

The computational companion is the ordered Notebook 01-08 sequence. Each
notebook may call tested code in `src/` or `scripts/`; no paper-facing output
requires a manual invocation outside that sequence.

| Paper-facing output | Canonical producer | Machine-readable or display output |
| --- | --- | --- |
| Table 1: selected products and empirical promotion support | Notebook 03 | `results/empirical_bayes/tables/paper_product_characteristics.{csv,tex}` |
| Table 2: demand-model predictive performance | Notebook 02 | `results/final/tables/final_demand_model_comparison.csv` and `paper/tables/table2_demand_model_performance.tex` |
| Figure 1: empirical promotion support and calibrated post-promotion effects | Notebook 05 | `results/empirical_bayes/figures/paper_promotion_depths_and_model_implied_post_effects.{png,pdf}` and `paper_model_implied_post_promotion_effects.csv` |
| Main three-policy grid and exact decomposition | Notebook 06 | `artifacts/policy/empirical_bayes_price_consistent/policy_optimization.pkl` and `results/empirical_bayes_price_consistent/tables/policy_results.csv` |
| Main-policy schedule diagnostics | Notebook 07 | `results/empirical_bayes_price_consistent/tables/three_policy_sequential_decomposition.csv` and related diagnostics |
| Figure 2: 48-week-normalized policy-value contrasts by capacity | Notebook 08 | `results/empirical_bayes_price_consistent/figures/three_policy_components_by_capacity_lambda_050_to_100_48_week_normalized.{png,pdf}` |
| Table 3: largest dynamic-myopic policy differences by capacity | Notebook 08 | `paper/tables/table3_main_policy_peaks.tex` |
| Table 4: robustness of peak total policy contrasts | Notebook 08 | `paper/tables/table4_robustness_peaks.tex` |
| Table 5: conditional behavioral uncertainty | Notebook 08 | `paper/tables/table5_behavioral_uncertainty.tex` |

Figure 3, the B=2 calendar-switching rug, is a diagnostic output rather than a
current manuscript figure. It is generated by Notebook 08 at
`results/empirical_bayes_price_consistent/figures/three_policy_switching_rug_B2.{png,pdf}`.

The paper-facing percentage denominator for Figure 2 and Tables 3-5 is the
specification-specific 48-week myopic-profit value evaluated over the same
common horizon. The 12-week planning-profit normalization remains an exported
diagnostic, not the primary paper measure.

All active policy-facing outputs use empirical-Bayes behavioral draws under
`artifacts/calibration/empirical_bayes/` and price-consistent policy artifacts
under `artifacts/policy/empirical_bayes_price_consistent/`. Legacy heuristic
artifacts are retained separately for provenance and are not inputs to the
outputs listed above.

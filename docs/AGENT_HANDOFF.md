## Confirmed bootstrap implementation

Confirmed from live current source, not legacy documentation.

- Resampling unit: `store_upc`, a product-store panel.
- Each bootstrap replication samples eligible panels with replacement, with
  sample size equal to the number of eligible panels.
- All eligible event summaries and price moments from a sampled panel receive
  the same cluster multiplicity, preserving within-panel temporal/event and
  price dependence.  Weeks and promotion episodes are not independently
  resampled.
- Product-specific calibrations are independently bootstrapped by product with
  seed `random_seed + product_index + 1`.
- Pooled calibration separately bootstraps pooled eligible panels.
- The EB mixture aligns a product bootstrap draw and sampled pooled draw by
  final bootstrap row/parent index. This is an EB pairing, not a common joint
  resample across products.

Code paths:

- product: `_bootstrap_product` in `calibration.py`;
- invocation and independent seeds: `calibrate_products`;
- pooled: `bootstrap_behavioral_moments`;
- aligned EB mixture: `_apply_empirical_bayes_draws`.

Paper-ready wording:

> Behavioral uncertainty is generated by resampling eligible product-store panels with replacement, preserving each sampled panel’s within-panel history of promotion events and price variation.

## Confirmed gross-margin / cost handling

Current implementation:

1. Read `gross_margin_pct_observed` and convert to a fraction (automatically
   dividing by 100 when the scale indicates percentage points).
2. Compute `unit_cost_observed = price * (1 - gross_margin_fraction)`.
3. Mark cost as missing if the margin is non-finite, outside `[-1.0, 0.95]`,
   the cost is non-finite, or the cost is non-positive.
4. Define product cost as the median of `unit_cost_observed` over calibration
   product-store-week rows. Pandas median ignores missing values.
5. Only if that median is absent/non-positive, use the pooled median cost.

Thus missing/invalid margins are **excluded**, not imputed or forward-filled.

Code paths:

- row-level construction: `_construct_observed_cost` in `calibration.py`;
- product median/fallback: `_product_economic_references` in `calibration.py`.
